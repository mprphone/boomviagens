# Boomviagens Front-office V7

Refatoração comercial do front-office: cabeçalho compacto, pesquisa aérea global, áreas metropolitanas/todos os aeroportos, date picker próprio, multi-cidade limpo, até 40 ofertas Duffel por pesquisa, checkout passo 1->2 robusto com erro visível, mobile first.

## Importante
O ambiente Duffel TEST pode devolver inventário muito reduzido. Isto não deve ser confundido com a quantidade de voos disponível em produção. A V7 não inventa resultados. Para volume real é necessário acesso LIVE e, se desejado, adicionar outras fontes aéreas.

Cruzeiros continuam a funcionar como pedido assistido enquanto não existir API de cruzeiros. Experiências agregam HBX Activities e Ticketmaster quando configurados.
